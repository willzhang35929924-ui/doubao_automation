# Mac 修复与验证范围

本次更新将 Mac 原生启动、账号登录、飞书同步和任务恢复的修复纳入源码与回归测试。通用安装方法见 [Mac 指南](macos.md)。发布包不包含任何人的配置、登录状态、视频、截图或运行诊断数据。

## 已修复

- 统一根目录与 `scripts/` 下的 Mac 入口，使用原生 Python 流程；不再要求 Docker CLI、Docker Desktop 或本机 Compose 覆盖文件。
- 首次准备缺失的虚拟环境、Python 依赖和可用浏览器；已有私有配置保留，缺失配置以私有权限初始化模板。
- 登录窗口使用可见的独立 Profile；验证有效会话和可用聊天界面，访客 Cookie 不算登录成功，启动失败返回真实错误。
- 飞书同步保留附件下载所需的权限参数，限制重试，保持 TLS 证书校验，拒绝错误页或不完整媒体，使用原子下载避免损坏已有文件。
- 产品与素材完整性统计、独立产品图库、普通同步恢复远端仍存在的本地删除行，以及同名附件的稳定隔离路径。
- 同一素材表同一提示词列的自动记录模式按当前行取提示词，避免把其他产品的首条指令拼入本次生成。
- 等待新会话和本次用户消息真正就绪，核对正式会话地址；按本次回复与视频卡片身份取回产物，避免误领旧视频。
- 已提交请求只恢复原会话。网页只加载最近消息时，只有原消息证明、同一正式会话、单任务及唯一完整登记的确认消息均成立，才允许恢复定位。
- 复用下载文件及重启恢复前校验资产身份、绑定记录、大小与 SHA256；未验证旧文件保留备份，不以文件存在或编码哈希不同推断生成成功。
- 视频库显示脚本与片段编号；成片存在时不重复展示对应 raw，原文件仍保留。

## 实际验证

2026-11-04 在 Apple Silicon ARM64 Mac 上完成了一轮真实视频生成主流程：4 条 15 秒、720×1280、24fps、有音轨的视频。逐条核对实际画面、文件完整解码、不同原会话/卡片及 HTTP 分段播放；最终任务完成 4/4、退出码为 0。重复启动复用了后台服务，任务与额度数据保持不变。

该轮是在发现错误后修复、核对原请求并续跑完成；不宣称从零全程无人干预。后续新增的通用首次安装流程有独立回归覆盖。网页结构、网络环境与官方额度会变化，更多机型、Intel Mac、多账号耗尽切换及所有异常分支不能据这一轮实测推断已验证。

审核后的 VSR 去水印与 SeedVR2 1080P 后处理未执行，适配器和模型不随仓库提供。实际平台产物保留生成标识，不能称为 4K/60fps 或无水印成片。登录、验证码、系统权限和协议始终由使用者按正常流程处理。
